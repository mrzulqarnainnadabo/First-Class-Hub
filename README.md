# First Class Hub

Responsive static website for First Class Hub, with a black-and-gold brand direction.

## Files
- `index.html` — homepage and responsive styling
- `logo.svg` — scalable logo artwork used in the header and browser tab

## Deploy on Vercel
Import this repository into Vercel. Framework preset: **Other**. Build command: leave empty. Output directory: `.`. The project is a static site and needs no build step.

## Before public launch
Confirm the official street address, opening hours, phone/WhatsApp contact, and conference booking workflow. Replace illustrative stock imagery with approved venue photographs. The current booking section is informational only and does not submit reservations.
