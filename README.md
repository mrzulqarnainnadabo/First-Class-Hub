# First Class Hub

Responsive static website for First Class Hub, with a black-and-gold visual direction.

## Project
- `index.html` — responsive homepage, accessible category filters, address and Google Maps directions.
- Static deployment; no build command or package manager is required.

## Local development
Open `index.html` in a browser or serve the repository root with any static file server.

## Launch blockers
- The approved logo image supplied for the launch is a JPEG (1254 × 1254 RGB). It has not yet been committed to this repository because the connected GitHub file-write workflow available for this task supports text files but does not provide a direct local-binary upload path. The existing `logo.svg` is not the supplied official artwork and must not be used as a substitute. Add the original supplied image as `assets/first-class-logo.jpeg`, then integrate it into the header, footer, favicon and social preview before launch.
- No canonical URL is set because the intended public production domain has not been confirmed.
- The Vercel project currently discoverable for this repository is named `first-class-hub-kano`. Do not deploy to it until the project owner confirms that it is the intended project and its location branding is corrected. The user brief explicitly limits the business to Kaduna.
- Product images are illustrative stock imagery, not verified photographs of the actual premises or inventory. Replace with approved real photographs when available.
- Opening hours, telephone, pricing, reviews and booking workflow are intentionally not asserted because verified details were not supplied.
